# Plushie Paradise — 少女心玩偶海外内容运营案例

> 一个为求职打造的海外内容运营作品集项目：围绕「少女心可爱玩偶」赛道，从市场调研、账号定位、内容策略到样例产出，完整呈现一套可执行的 TikTok / Instagram 内容运营方案。

## What is this project?

This repository is a **portfolio case study** built for job applications in cross-border e-commerce and overseas content operations. It documents a complete, executable content operation plan for the **cute plush toys** niche on TikTok and Instagram — one of the hottest young-female content and e-commerce tracks in overseas markets.

It covers:

- **Market research** — why the cute plush niche is trending, and who the audience is
- **Account positioning** — persona, differentiation, visual identity
- **Content strategy** — content pillars, posting calendar, hashtag and caption strategy
- **Sample content** — original English captions, video scripts & Canva/CapCut production blueprints
- **A 30-day growth plan** with data tracking

## Why this niche

我选这个赛道，是因为「情绪价值消费」正在成为海外 Z 世代最强的消费驱动力之一：TikTok 上 #emotionalsupport（情感支持）话题播放量超过 **9.39 亿次**；一只国内批发价 2-3 元的玩偶在 TikTok 美区能卖到 **$5.77** 并登顶玩具类目销量榜。少女心玩偶 = 高颜值 + 强情绪 + 好出片，天然适合海外内容种草。
