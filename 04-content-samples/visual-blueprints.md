# 04 · Sample Content — Visual Production Blueprints（Canva / 剪映制作蓝图）

> **为什么样例图文要你亲手做？** 面试官一定会追问细节（你用的什么字体、怎么构图、为什么这么排）——自己做的才讲得出来，AI 生成的不算你的能力。下面是两张图的完整蓝图，照着做即可，预计每张 20-30 分钟。

## Graphic 1 — 封面图（竖版 1080×1920）

从上到下：

1. **顶部大标题**：*"Meet Mochi 🧸"*（Canva 字体选圆润体，如 Baloo 2 / Fredoka / 系统圆体）
2. **中部主图**：玩偶居中特写（用你手边的玩偶自己拍，或 Canva 素材库搜 plush / teddy bear；**注意商用版权**，自己拍的图最安全）
3. **底部英文小字**：*"softness you didn't know you needed"* + 账号名 @plushie.paradise
4. **整体**：奶油色 / 柔光滤镜，背景浅粉或米白，点缀 sparkle / sticker 贴纸

## Graphic 2 — 布置图（1:1 方图）

1. **左上角标题**：*"cozy corner update ✨"*
2. **主画面**：玩偶坐在书桌 / 床头一角，旁边放小台灯、小花瓶（氛围感）
3. **底部三行小字**：*plushie + warm light + something soft*
4. **统一色调**：米白 + 藕粉

## Canva 操作速查

1. 新建 → 自定义尺寸 → 输入 `1080 × 1920`（或 `1080 × 1080`）
2. 上传自己拍的玩偶照片，或搜索 plush / teddy bear 素材
3. 文字 → 选圆润字体 → 调色（奶油白 `#FFF5EE`、藕粉 `#F7C8D0`）
4. 元素 → 搜 sparkle / sticker 加贴纸 → 导出 PNG
5. 版权提示：Canva 免费素材先确认「可免费商用」，自己拍的图最稳妥

## 剪映短视频速查（配合 video-scripts.md）

1. 导入拍摄素材（竖屏）→ 先粗剪掉废镜头
2. 按脚本加英文字幕（样式统一：白字 + 黑描边，居中偏下）
3. 选轻快 BGM → 手动卡点（转场处对齐节拍）
4. 滤镜：奶油 / 柔光 → 导出 1080p
