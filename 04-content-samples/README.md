# 04 · 样例内容 Content Samples

> 这一栏是项目的「作品」，必须你亲手做出来（我可以全程教 + 帮你生成素材）。
> 目标产出：**2 张英文图文（Canva）+ 1~2 条短视频（剪映）**。

## 要做的东西

### A. 英文图文（Canva 做 2 张）

1. **封面图**：一只玩偶 + 英文标题（如 "Meet Berry, today's plushie pick 🍓"）
2. **详情图**：玩偶 3 个亮点（英文），或"今天抱哪只"投票

### B. 短视频（剪映做 1~2 条）

选题从内容栏目里挑，每条 15–30 秒，英文标题/字幕。

## 视频脚本模板（英文）

| 时间 | 画面 | 字幕/文案 |
|---|---|---|
| 0–3s | 玩偶特写，悬念开场 | Hook: "You won't believe how soft this is…" |
| 3–10s | 开箱/展示 |  |
| 10–20s | 亮点特写 |  |
| 20–30s | 结尾 + CTA | "Follow for daily cuteness!" |
