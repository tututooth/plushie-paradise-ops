## 数据复盘速查（配合 06 表）

- **互动率** = (点赞 + 评论 + 收藏 + 转发) ÷ 播放量
- 看数据顺序：先看播放（流量池），再看互动率（内容质量），最后看涨粉（转化效率）
- 每周一在 `06-data-tracking-template.csv` 末尾加一行「周汇总」，把一周数据合计一次

3. **我做了**：4 个内容栏目 + 30 天增长计划 + 3 条英文文案 / 2 条视频脚本 + 数据复盘表；
4. **我的收获**：________（填学习日志）
