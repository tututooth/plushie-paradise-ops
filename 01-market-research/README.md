# 01 · 市场调研 Market Research

> 调研目标：用**真实可查的信息**回答「为什么做少女心玩偶这个赛道」。
> 完成后把结论填进下方模板，并记录信息来源（链接）。不需要写代码，用 AI 辅助搜索 + 肉眼观察即可。

## 怎么查（建议 2 天内完成）

1. **TikTok Creative Center**（ads.tiktok.com/business/creativecenter）— 看玩偶/盲盒相关热门标签与素材
2. **Google Trends**（trends.google.com）— 搜 `plush toy` / `stuffed animal` / `blind box` 看趋势
3. **TikTok 搜索** — 输入 `#plushie` / `#stuffedtoys` / `#blindbox`，记录热门视频的播放量、点赞、评论
4. **小红书/抖音搜索** — 看国内同赛道怎么玩，找可迁移的选题灵感（注明是参考）
5. **竞品账号** — 找 3 个做玩偶内容的海外账号，记录粉丝量、内容风格、更新频率
